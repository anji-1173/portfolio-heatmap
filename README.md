# portfolio-heatmap

保有している日本株・米国株・暗号資産の銘柄を、リアルタイム株価・チャート・ヒートマップ・企業概要で確認できるアプリです。

**評価額(保有金額)は一切表示しません。** 表示するのは銘柄そのものの値動きだけです。

## 使っている情報源(登録・APIキー不要)

- 日本株・米国株の価格情報:Yahoo!ファイナンスの公開データ
- 暗号資産の価格情報:CoinGecko の公開データ

いずれも会員登録やAPIキーの取得は不要です。ブラウザから直接ではなく、サーバー(`server/index.js`)を経由して取得します。

## 動かし方

```bash
npm install
npm start
```

起動後、ブラウザで `http://localhost:3000` を開いてください。

## 画面の見方

- タブ切り替え:日本株 / 米国株 / 暗号資産 / ファンド(一覧のみ・リアルタイム価格対象外)
- 前日比 / 月間比の切り替え:ヒートマップの色が上昇(緑)・下落(赤)で変わります
- 銘柄タイルをクリック:右側に値動きチャートと企業概要(業種・事業内容)が出ます

## データについて

`data/holdings.json` に、保有銘柄の名前・種別・ティッカー(銘柄コード)を保管しています。金額は含んでいません。
一部の銘柄(非上場企業、コード特定不可のもの)は価格取得の対象外です。
